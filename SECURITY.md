# Security Policy

This extension is part of the Nephilex project and follows its security policy:
<https://github.com/nephilex/nephilex/security/policy>

Please report vulnerabilities in the extension privately through GitHub private vulnerability
reporting on the main repository:
<https://github.com/nephilex/nephilex/security/advisories/new>

Do not open a public issue, pull request, or discussion for a suspected vulnerability. Mention
that the report concerns the VS Code extension and include the extension version, the editor
and its version, and the Nephilex CLI version (`nephilex --version`).

Only the latest released version of the extension receives security fixes.
